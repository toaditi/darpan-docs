## Recently shipped

<div className="rm-card">
  <p><strong>v1.5.0 — Slack alerts, database sources, and shared configuration</strong> <span className="rm-pill">Shipped · Aug 26, 2026</span></p>
  <p className="rm-muted">Run-completion alerts post to Slack as well as Google Chat, and lead with a verdict instead of a table of counts. Databases become a first-class source — MySQL, PostgreSQL and Db2 — and a run can compare two instances of the same system. A source or auth connection can be shared with another tenant, schemas can be built from a CSV header row, and automations report and re-sync drift from their saved run. Scheduled runs now verify their differences the way hand-started runs always have, so both report the same numbers. Ships with app v2.6.0; see [Release updates](/releases/updates).</p>
</div>

<div className="rm-card">
  <p><strong>v1.4.0 — follow a run you started, and transfer orders</strong> <span className="rm-pill">Shipped · Aug 7, 2026</span></p>
  <p className="rm-muted">Start an automation by hand and watch it from the moment it begins — the timeline advances stage by stage, Cancel stops the run, and a failure shows its full error text instead of a message cut short. Notifications hold up across retries, including when an automation gives up. HotWax transfer orders reconcile as their own source system, matched on order date. Ships with app v2.5.0; see [Release updates](/releases/updates).</p>
</div>
